# simulation/

**Reserved for Future Network Simulation**

This directory will contain simulation tooling to test the SYNC BLE mesh network without physical devices.

## Planned Capabilities
- Simulate multiple virtual SYNC nodes
- Model BLE range and connectivity
- Test store-carry-forward message delivery paths
- Measure message propagation latency across different network topologies
- Test TTL and hop-count expiry behaviour

## Potential Tools
- Node.js simulation scripts
- Bluetooth mesh simulation library
- Automated test scenarios (network partition, mobile node, etc.)
